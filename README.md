# AbeloHost

* PHP 8.1
* MySQL 9
* Smarty 5

## Разворачивание:

1. Клонировать репозиторий:

       git clone git@github.com:yvalynets/abelo-host.git

2. Скопировать `.env.example` в `.env`. При необходимости изменить настройки:
    * `DOCKER_UID` - ID пользователя Linux (по умолчанию 1000)
    * `DOCKER_GID` - ID группы Linux (по умолчанию 1000)
    * `DOCKER_SITE_PORT` - порт на хосте для доступа к сайту (по умолчанию 80)
    * `DOCKER_DB_PORT` - порт на хосте для доступа к базе данных (по умолчанию 3306)

3. Собрать и запустить контейнеры:

       docker compose up -d

4. Добавить пакеты:

       docker compose exec -u www-data php composer install

5. Запустить сидер:

       docker compose exec -u www-data php php bin/seed.php

## Примечания

### Главная страница

Делается 1 запрос для получения списка категорий + по 1 запросу на каждую категорию для получения списка статей. В
реальном проекте стоило бы получать все данные за 1 запрос.

### Станица статьи

Просмотры увеличиваются при переходе на страницу статьи, при этом на сутки добавляется кука. Если пользователь уже видел
статью, то просмотры не увеличиваются.

Под похожими понимаются статьи, которые находятся в той же категории. Они отсортированы по просмотрам.

В хлебных крошках указывается первая категория. В реальном проекте стоило бы добавить понятие "главной" категории. Тогда
на странице статьи, в хлебных крошках можно будет показывать категорию, из которой перешли, либо главную, если перешли
не из категории.

Картинка статьи на странице статьи и в превью одна и та же. В реальном проекте стоит сохранять оригинал картинки и
дополнительно нарезать эскизы для страницы и превью.

### Общее

Настройки проекта (сколько чего выводить, как сортировать и т.д.) находятся в файле `config/config.php`.

Роутинг осуществляется в `index.php`. В реальном проекте при большом количестве роутов можно вынести в отдельный класс.

В адресе страниц категорий и статей используются id. В реальном проекте можно добавить ЧПУ адреса.

CSS-файл пересоздается в реальном времени с помощью `sass` в контейнере `node`. Для получения сжатого файла нужно
выполнить команду

       docker compose exec -u node node npm run build

### Сидер

Сидер генерирует текст через пакет `fakerphp/faker`. При первом выполнении сидера, он скопирует 10 картинок
с https://picsum.photos/ (~400KB), которые будут использоваться в качестве превью статей.

Сидер поддерживает параметры:

* `--fresh` - выполнится предварительная очистка базы данных
* `--categories` - количество создаваемых категорий (по умолчанию 10)
* `--articles` - количество создаваемых статей (по умолчанию 50)

Например:

       php bin/seed.php --fresh --articles=100 --categories=5

Заданные параметры сидера:

* ~10% категорий без статей
* ~30% категорий без описания
* ~30% статей без описания
* ~10% статей без картинки
* ~20% статей без просмотров
* у статьи может быть от 1 до 3 категорий
